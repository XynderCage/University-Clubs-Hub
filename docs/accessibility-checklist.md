# Accessibility checklist — Lab 10
- [x] Semantic landmarks and descriptive H1.
- [x] Explicit persistent labels.
- [x] Keyboard-operable form.
- [x] Visible `:focus-visible` outline.
- [x] Status announced through `role=status` and `aria-live=polite`.
- [x] State communicated with text, not colour alone.
- [x] Responsive single-column narrow-screen layout.
- [ ] Verify contrast against WCAG 2.2 AA using tools and manual inspection.
- [ ] Test 200% zoom and 320 CSS-pixel viewport.
- [ ] Test NVDA/VoiceOver and keyboard-only use.
- [ ] Associate inline errors with fields using `aria-describedby` when added.
- [ ] Conduct evaluation with users with diverse access needs.

Checked means source markup/styles provide the feature; it is not a substitute for assistive-technology evaluation.
